# Сборка lab3.exe

Нужен только [uv](https://docs.astral.sh/uv/). Python и PyInstaller uv скачает сам.

## Команда

Из папки `lab3`:

```bash
uv run --with pyinstaller pyinstaller --onefile --windowed --name lab3 src/lab3/__main__.py
```

Готовый файл: `dist/lab3.exe`. Его можно копировать куда угодно, рядом ничего не нужно.

- `--with pyinstaller` — uv ставит PyInstaller только на эту команду, в `pyproject.toml` он не попадает;
- `--onefile` — всё в один exe;
- `--windowed` — без чёрного окна консоли;
- `--name lab3` — имя файла;
- `src/lab3/__main__.py` — точка входа (запускает окно программы).

## После сборки

- Папку `build/` и файл `lab3.spec` можно удалить: это промежуточные файлы.
- Первый запуск exe занимает пару секунд: он распаковывается во временную папку.
- Файл буфера задания 1 `task1_buffer.txt` создаётся в папке, откуда запущен exe.

## Пересборка

После изменений в коде просто повторить команду. Если что-то странное — удалить `build/`, `dist/`, `lab3.spec` и собрать заново.

## Запуск без сборки

```bash
uv run lab3
```
